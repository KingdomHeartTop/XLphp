## What is XLphp?

XLphp is a **minimalistic alternative to PHP** with Python/Go-like syntax but full PHP power.

### Features:
- No `$` for variables
- Short functions (`func add(a,b) => a+b`)
- Custom keywords (`when` instead of `if`, `loop` instead of `foreach`)
- Full compatibility with PHP libraries
- Easy to learn in 1 hour
